Automated Fault Detection & Diagnostic Benchmark
F1: Incorrect VLAN Assignment: VLAN 20 Missing on Trunk — SW1 (FastEthernet0/24)
DETECTED

VLAN 20 was excluded from the allowed trunk VLAN list on SW1 port FastEthernet0/24 connecting to SW2.

Impact: Guest endpoints and wireless AP clients connected to SW2 are partitioned from R1; DHCP requests fail and clients receive 169.254.x.x.

Evidence: switchport trunk allowed vlan 10,30,99 (VLAN 20 not allowed).

Corrective Action:
SW1(config)# interface FastEthernet0/24 SW1(config-if)# switchport trunk allowed vlan 10,20,30,99
F2: Missing DHCP Configuration: EMPLOYEE Pool Absent — R1 Router
DETECTED

The DHCP pool for VLAN 10 (EMPLOYEE) is missing from R1 configuration.

Impact: Employee desktop PCs fail to acquire network settings via DHCP DORA and cannot reach the internal server or internet.

Evidence: DHCP pools defined on R1: ['GUEST'] (EMPLOYEE missing).

Corrective Action:
R1(config)# ip dhcp pool EMPLOYEE R1(dhcp-config)# network 10.10.10.0 255.255.255.0 R1(dhcp-config)# default-router 10.10.10.1 R1(dhcp-config)# dns-server 10.10.30.10
F3: Incorrect Gateway Address on Subinterface — R1 (GigabitEthernet0/0.10)
DETECTED

Subinterface GigabitEthernet0/0.10 is configured with IP 10.10.10.254, but the network plan and DHCP specify 10.10.10.1.

Impact: Employee PCs sending packets to 10.10.10.1 fail ARP resolution; inter-VLAN routing and internet connectivity break.

Evidence: ip address 10.10.10.254 255.255.255.0 on GigabitEthernet0/0.10.

Corrective Action:
R1(config)# interface GigabitEthernet0/0.10 R1(config-subif)# ip address 10.10.10.1 255.255.255.0
F4: Missing NAT / PAT Translation Configuration — R1 Router
DETECTED

R1 has no dynamic PAT overload statement linking internal branch subnets to WAN interface GigabitEthernet0/1.

Impact: Internal 10.10.0.0/16 packets exit to ISP without translation; ISP drops RFC 1918 private source packets.

Evidence: No 'ip nat inside source list ... overload' detected in configuration.

Corrective Action:
R1(config)# ip access-list standard 1 R1(config-std-nacl)# permit 10.10.0.0 0.0.255.255 R1(config)# ip nat inside source list 1 interface GigabitEthernet0/1 overload
F5: Incorrect Guest ACL: Internal Subnet Denials Missing — R1 (ip access-list extended GUEST-IN)
DETECTED

The Guest ACL contains a broad 'permit any' without preceding 'deny' rules for Server VLAN (10.10.30.0/24) and Management VLAN (10.10.99.0/24).

Impact: Severe security breach: Guests can access internal company server and switch management interfaces directly.

Evidence: ACL GUEST-IN permits 10.10.20.0/24 to any without blocking 10.10.30.0/24 or 10.10.99.0/24.

Corrective Action:
R1(config)# ip access-list extended GUEST-IN R1(config-ext-nacl)# 10 deny ip 10.10.20.0 0.0.0.255 10.10.30.0 0.0.0.255 R1(config-ext-nacl)# 20 deny ip 10.10.20.0 0.0.0.255 10.10.99.0 0.0.0.255 R1(config-ext-nacl)# 30 permit ip 10.10.20.0 0.0.0.255 any
